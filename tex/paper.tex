\begin{abstract}
An automated auditor reads code it did not write and decides whether to block it. We measure what
moves the limit on how much it catches, against ground truth no model supplies (hidden test suites
run by an interpreter), varying one factor at a time on 110 defective and 150 correct increments.
Eight independent readings of a shipped cross-vendor auditor reach 30.0\% union recall $[20.0,
40.7]$ at 16.0\% false positives, and the eighth still adds 1.9 points: returns diminish, with no
plateau shown. A stronger same-vendor model moves recall by $-26.4$ points $[-37.3, -15.6]$, a
preregistered primary, but the sign reverses under a weaker severity rule, so we read it as
calibration and sampling, not auditing ability. One added rulebook sentence moves flags by $+26.8$
points on an exploratory arm and does not measurably move hidden-suite pass rate. Of 57 defects no
reading flagged, two raters, one an author, judge 44 to be failures the specification never
determined. Adding a behavioural rule to the specification with the code held fixed raised
adjudicated diagnosis from 0 to 9 of 32 selected instances, against 0 under a placebo edit, but
only where the added rule agreed with the hidden suite. A recall figure is therefore a property of
auditor, rulebook, decision rule and benchmark together, and is not portable without its
false-positive rate. Every study was preregistered, with one named exception; each report is
marked by whether it passed independent cross-vendor review, and the reviews are archived beside
the records.
\end{abstract}

\section*{Limitations}
\textbf{Substrate.} Every measurement here is on function-level Python tasks from two code
benchmarks. Nothing in this paper establishes that the same ceiling, or the same explanation for
it, holds for another language, for repository-scale changes, or for code whose correctness is
not decided by an executable suite.

\textbf{The ground truth is a test suite, and a test suite is not a specification.} Hidden
suites encode a reference implementation's behaviour, including behaviour its prose never fixed.
In the intervention study reported in \S\ref{sec:inreview}, a generator shown an instance's
failing inputs inferred a behavioural rule that \emph{contradicted} the hidden oracle on 23 of
32 instances. That is a property of the benchmarks, not of the generator, and it bounds what any
recall figure measured this way can mean.

\textbf{Intervals of unverified coverage.} The primary intervals are percentile bootstraps over
problem clusters whose coverage under this design has not been validated; in simulation the
construction under-covers by roughly 2 to 5 points. Two earlier constructions in this programme
were found by review to cover $0.416$ and $0.075$ where $0.95$ was claimed. We state coverage as
unverified rather than assume it.

\textbf{The validation instrument shares the failure mode under study.} Reports were checked by a
language model, which is what this paper measures a ceiling on. Studies cleared review at rounds
4, 6, 7, 9, 10 and 11, so a single pass has low recall; no measurement ever moved, so on
recomputation it is strong and on interpretation weak; and withholding our conclusions from one
pass produced six substantive findings that six briefed passes had missed. The defect class it
leaves open is the one that looks right to a language model, and we do not know what remains in
it.

\textbf{The reviewer is one of the measured families.} \texttt{gpt-6-astra} reviewed every
report in this programme and is also an auditor route whose ranking against the others the paper
reports. For claims about \texttt{astra}'s relative performance the validation is a
self-assessment, and those comparisons should be treated as bracketed until a model that audited
nothing here has checked them.

\textbf{No rater from outside the project.} Every human judgement in this work is the first
author's. A third model rating does not discharge that, and the design that asks for an outside
human has not been run.

\textbf{Budget.} Reading depth $K$, the number of arms, and the size of every intervention
population were set by cost rather than by a power calculation, and no sample size was justified
in advance by a minimum-detectable-effect argument.

\section*{Reproducibility and claims}
The claims this paper is willing to defend, each with the interval and the label its source report
gives it, are listed in \texttt{CLAIMS.md} in the repository at
\url{https://github.com/dongzhaohe321418-lab/audit-ceiling-paper}, together with the claims the
evidence does not support. Every preregistration, every numbered amendment, every report and every
independent review is archived there verbatim, including the reviews that refused approval. The
repository also carries the auditor's constitution, the exact prompts for the auditor, the
generator and each rating rubric, the capability card of every route with its sampling parameters,
the frozen instance manifests with their hashes, and the analysis code that produces every number
and figure below from those records. What the repository cannot carry is the raw run
directories themselves. They contain model outputs derived from corpora under a
non-commercial, no-redistribution licence, so what is published is every derived record --
scores, counts, hashes, labels, prompts and manifests -- and not the bytes they were derived
from. A replication therefore reproduces every number in this paper from the committed records,
and reproduces the records themselves only by re-running the studies against the same corpora.
The repository is private while the remaining study is in review and is released with the
paper.
