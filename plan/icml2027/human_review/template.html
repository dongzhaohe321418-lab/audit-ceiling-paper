Human review pack

For a co-author. About an hour. Nothing is sent anywhere: your answers stay in this browser until you export them.

What to do

  1. Part 1: judge 41 short programming tasks. Please do this first, before reading anything about the paper, and don't run code or look the tasks up.
  2. Part 2 unlocks when every task has both answers: three short questions about the paper.
  3. Press Export answers at the bottom and send the downloaded file back. If the download is blocked, use Copy answers and paste them into a message.

Answers are saved in this browser as you go, so you can close the file and continue later on the same computer and browser.
